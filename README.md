### Featured project

> **🗳️ Voxly — Live Polling Platform**
>
> A full-stack polling and feedback platform built solo for a hackathon. Logged-in users create polls, share via a public link, collect anonymous or authenticated responses, and watch results update live via WebSockets. Built with Node, Express, PostgreSQL (JSONB schema for nested questions/options), and Socket.io. JWT auth + bcrypt, with a small custom OIDC client.
>
> &nbsp;&nbsp;[`Code →`](https://github.com/TheOmRaj/Voxly-Live-Polling-Platform) &nbsp;&nbsp; [`Live →`](https://voxly-live-polling-platform-production.up.railway.app)
